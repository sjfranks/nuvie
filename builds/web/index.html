Nuvie

The open source engine for Ultima VI, Martian Dreams and The Savage Empire, running in your browser.

Loading the engine…

Nuvie needs the original game's files, which you must own (Ultima VI is sold by GOG, for example). Import the folder that holds them, or a .zip of it. The files and your saved games stay in this browser's storage; nothing is uploaded anywhere.

In the game: the mouse or the arrow keys move, and the original keyboard commands work (Alt+X or Ctrl+Q quits, Alt+S saves).
